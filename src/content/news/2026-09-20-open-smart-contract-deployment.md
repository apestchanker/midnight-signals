Until now, private smart contract deployment on Midnight Mainnet has been
gated: only a small, whitelisted set of applications (such as AscendPerps)
could run in what Guillemot described as a "gated garden."

In a post on X, Guillemot confirmed that this restriction is coming off soon:

- **Open deployment** — any developer will be able to experiment with and
  deploy private smart contracts on Mainnet, not just whitelisted apps.
- **Private custom tokens** — the upgrade enables minting private,
  Zcash-style custom tokens. In this initial phase they can already be used
  in select DeFi scenarios through Offer Files.
- **Composability, later** — Guillemot noted a *subsequent* version of smart
  contracts will add events and composability, letting contracts communicate
  with each other and enabling more complex DeFi (his example: something like
  an Aave-style lending protocol).

No firm activation date was given beyond "soon." Builders currently targeting
the whitelisted model should watch official channels for the exact rollout
window before assuming open deployment is live.
